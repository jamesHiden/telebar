# تله‌بار

سایت سفارش آنلاین سبزی و صیفی‌جات تازه، مخصوص کسب‌وکارهای غذایی با مصرف کم و روزانه: ساندویچی/پروتئینی، آب‌میوه و آب‌هویج‌گیری، رستوران‌ها.

مشتری شب قبل سفارش ثبت می‌کنه، صبح زود درب مغازه تحویل می‌گیره. حساب‌وکتاب به‌صورت نسیه (بدهی/پرداخت) مدیریت میشه — بدون نیاز به گیت‌وی پرداخت آنلاین.

## راه‌اندازی

```bash
npm install
cp .env.example .env.local   # و مقادیر رو پر کنید (SESSION_SECRET با: openssl rand -base64 32)
```

`DATABASE_URL` رو هم در `.env.local` به یه دیتابیس Postgres وصل کنید (برای تست محلی می‌تونید یه Postgres رایگان روی [Neon](https://neon.tech) یا [Vercel Postgres](https://vercel.com/storage/postgres) بسازید، یا از یه Postgres محلی استفاده کنید).

```bash
npm run seed   # می‌سازه: حساب ادمین + لیست اولیه‌ی کالاها (جدول‌ها هم خودکار ساخته میشن)
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) بالا میاد.

- ورود ادمین: با `ADMIN_PHONE` / `ADMIN_PASSWORD` که در `.env.local` گذاشتید، از صفحه‌ی `/login` وارد بشید (خودکار به `/admin` هدایت میشه).
- مشتری جدید از `/register` ثبت‌نام می‌کنه.

## ساختار

- `lib/db.js` — دیتابیس Postgres (مشتریان، کالاها، سفارش‌ها، پرداخت‌ها) — جدول‌ها در اولین اجرا خودکار ساخته میشن
- `lib/session.js` / `lib/dal.js` — نشست (JWT در کوکی httpOnly) و لایه‌ی احراز هویت
- `app/actions/*` — Server Actionها برای ثبت‌نام/ورود، ثبت سفارش، و عملیات ادمین
- `proxy.js` — محافظت از مسیرهای `/dashboard` و `/admin`
- `app/page.js` — صفحه‌ی معرفی (برای نشون‌دادن حین پیچ حضوری)
- `app/dashboard` — پنل سفارش‌گیری مشتری
- `app/admin` — پنل مدیریت قیمت/موجودی، سفارش‌های روز، و حساب مشتریان

## استقرار روی Vercel

1. یه ریپازیتوری گیت‌هاب بسازید و این پروژه رو push کنید.
2. توی [vercel.com](https://vercel.com) با گیت‌هاب لاگین کنید → **Add New → Project** → ریپوی این پروژه رو انتخاب کنید → **Import**. Vercel خودش تشخیص میده Next.js هست، نیازی به تنظیم خاصی نیست.
3. قبل یا بعد از اولین دیپلوی، از تب **Storage** پروژه، یه دیتابیس **Postgres** بسازید (بر پایه‌ی Neon، رایگان برای شروع) و به پروژه وصلش کنید — Vercel خودکار متغیر `POSTGRES_URL` رو ست می‌کنه.
4. توی **Settings → Environment Variables** این‌ها رو هم اضافه کنید:
   - `SESSION_SECRET` (خروجی `openssl rand -base64 32`)
   - `ADMIN_PHONE` و `ADMIN_PASSWORD`
   - `CUTOFF_HOUR` (اختیاری، پیش‌فرض ۲۱)
5. Deploy کنید. بعد از اولین دیپلوی موفق، یه‌بار از روی سیستم خودتون با `DATABASE_URL` ست‌شده روی همون رشته‌ی اتصال Postgres که Vercel ساخته، دستور `npm run seed` رو اجرا کنید تا حساب ادمین و لیست اولیه‌ی کالاها ساخته بشه (رشته‌ی اتصال رو از تب Storage همون دیتابیس در Vercel کپی کنید).
6. بعداً که دامنه‌ی اختصاصی خریدید، از **Settings → Domains** پروژه در Vercel اضافه‌ش کنید — نیازی به تغییر کد نیست.

## تست منطق دیتابیس (بدون نیاز به مرورگر)

```bash
node scripts/smoke-test.mjs
```

ثبت مشتری، سفارش، تحویل و پرداخت رو شبیه‌سازی و صحت محاسبات مانده‌حساب رو چک می‌کنه.

## محدودیت‌های نسخه فعلی (فاز ۱ — قابل توسعه)

- ورود فقط با شماره‌موبایل + رمز عبور؛ افزودن OTP پیامکی نیاز به یک سرویس پیامکی ایرانی (مثل کاوه‌نگار) داره.
- نقشه‌ی لوکیشن با OpenStreetMap/Leaflet (بدون کلید API، بدون ریسک محدودیت دسترسی).
- فقط یک ادمین پشتیبانی میشه.
- بدون گیت‌وی پرداخت آنلاین — حساب‌وکتاب نسیه‌ایه (می‌تونید بعداً زرین‌پال/آیدی‌پی اضافه کنید).
